## ⚠️ 먼저 읽어 주세요

* 운전 보조 기능입니다. **항상 전방을 보고, 언제든 직접 운전할 준비**를 해 주세요.
* 설정을 함부로 바꾸면 사고 위험이 있으며, **사고 · 고장은 본인 책임**입니다.

* **신호등 표시와 초록불 알림은 아직 제대로 작동하지 않을 수 있습니다.** 신호등을 카메라로 직접 보는 것이 아니라 주행 모델의 예측으로 짐작하는 기능이라, 늦게 켜지거나 틀리게 켜질 수 있습니다. **차는 신호를 보고 멈추거나 출발하지 않습니다.** 빨간불에서는 반드시 직접 브레이크를 밟고, 출발 전에는 꼭 신호를 직접 확인해 주세요.

## 2. 운전하는 방법

* **켜고 끄기는 핸들 버튼으로만** 합니다. 페달이나 속도로 저절로 켜지지 않습니다. (당근과 같은 규칙)
  * **크루즈 버튼**: 순정 SCC 차는 누르면 **조향**이 켜지고, 다시 누르면 모두 꺼집니다. 롱컨 차는 크루즈 버튼으로 끄기만 하고, 켜는 것은 SET / RES로 합니다.
  * **SET(-) / RES(+)**: **가감속**을 켭니다. SET은 지금 속도로, RES는 이전 설정 속도로 켜집니다. 롱컨 차는 조향도 같이 켜집니다.
  * **CANCEL**: 짧게 누르면 **가감속만 꺼지고 조향은 남습니다** (SET / RES로 다시 켜기). 0.4초 넘게 누르면 모두 꺼집니다.
  * 순정 SCC 차에서 크루즈 대기는 켜진 채 openpilot만 꺼져 있으면, SET / RES로 차의 SCC가 켜질 때 openpilot도 같이 켜집니다.
* **+ / - 버튼** (가감속이 켜져 있을 때): 설정 속도를 바꿉니다 (한 번에 10km/h, 주행 → 크루즈 버튼에서 바꿀 수 있음).
* **차간 거리 버튼**: 앞차와의 거리를 1~4단계로 바꿉니다. 주행 화면 왼쪽의 막대로 보입니다.
* **가속페달**: 밟는 동안만 운전자가 가속하고, 떼면 다시 openpilot이 제어합니다.
* **브레이크**: 조향은 그대로 두고 가감속만 잠시 꺼집니다. 떼면 다시 켜지는 방식은 주행 → **브레이크 후 다시 켜기**에서 고릅니다 (처음 값: 줄인 그 속도로 다시 켜짐).
* **차선 변경**: 시속 30km 이상(조향 → 차선변경 최소 속도)에서 방향지시등을 켜면 자동으로 차선을 바꿉니다. 옆 차로 뒤에 차가 있거나(후측방 감지) 도로 끝이면 바꾸지 않고 기다리며, 그때는 핸들을 그쪽으로 살짝 밀어야 바꿉니다.
* **신호등**: 차는 신호를 보고 서거나 출발하지 않습니다. **빨간불에는 직접 브레이크로 멈춰 주세요.** 앞차를 따라 서는 것은 됩니다.
* **운전자 모니터링**: 앞을 보지 않으면 경고 후 감속합니다. 방식은 설정 → 토글 → **운전자 모니터링**에서 고릅니다.

## 3. 주행 화면 설명

<p align="center"><img src="docs/assets/optech_hud.jpg" width="100%"></p>

> 그림의 숫자는 아래 표의 번호입니다. 시험용 값으로 모든 표시를 한꺼번에 켠 화면이라, 실제 주행에서는 상황에 따라 일부만 보입니다.

| 번호 | 표시 | 무엇인가요 / 언제 나오나요 | 켜고 끄기 |
|---|---|---|---|
| 1 | **연결 표시** | 지금 연결된 것을 작은 표로 보여 줍니다. SCC2 · TMAP/CARROT · RADAR (아래 [그림에 없는 표시](#그림에-없는-표시) 참고) | 화면 → **연결 상태 표시** |
| 2 | **GPS** | 막대 4칸 = 신호 세기. 초록 '잡힘' = 정상, 주황 '찾는 중 · 약함', 회색 '꺼짐', 빨강 '안테나 이상'. 시동이 켜져 있을 때만 동작 | 화면 → **GPS 상태** |
| 3 | **제한속도** | 설정 속도 아래 왼쪽 칸(흰 바탕, 빨간 테두리, 빨간 숫자). 지금 달리는 도로의 제한 속도 | 폰 내비 앱(TmapNda·당근내비)이 연결돼 있을 때만 보임. 연결돼 있으면 늘 같은 자리, 정보가 없으면 숫자 대신 빨간 가로 막대 |
| 4 | **단속속도 · 남은 거리** | 그 오른쪽 칸(노란 바탕, 빨간 테두리). 앞 과속카메라의 제한 속도, 남은 거리는 그 아래 작은 칸(200m 안이면 빨간 칸). 정보가 없으면 숫자 대신 빨간 가로 막대. 제목이 **구간단속**이면 구간단속 중, **방지턱**이면 과속방지턱 그림이 나옵니다 | 내비 연동 또는 주행 → **카메라 감속 + 내장 카메라 DB** |
| 5 | **설정 속도** | 크루즈 설정 속도. 칸 색으로 상태를 알려 줍니다 (아래 [설정 속도 칸 색](#설정-속도-칸-색)). 점선 오른쪽 **감속목표** 숫자는 카메라 · 커브 때문에 오픈파일럿이 낮춰서 맞추려는 속도입니다 (노란색. 감속하지 않거나 차가 멈춰 있을 때는 노란 가로 막대) | 늘 보임. 핸들 + / - 버튼으로 바꿈 |
| 6 | **차간 거리 · 기어** | 왼쪽 막대 = 차간 거리 단계(1~4칸). 순정 SCC 차는 차의 설정, 롱컨 차는 openpilot 설정. 오른쪽 = 기어 (D 초록, R 빨강, N 주황, P 회색) | 늘 보임. 핸들 차간 버튼으로 바꿈 |
| 7 | **큰 속도 · GPS 속도** | 계기판 속도. 흰색 = 일정, **빨강 = 감속 · 브레이크**, **초록 = 가속**. 아래 초록 **GPS** 숫자는 GPS로 잰 실제 속도 (계기판은 보통 몇 % 높게 나옵니다) | 늘 보임 |
| 8 | **신호등** ⚠️ | 빨간불 · 초록불을 **주행 모델의 예측으로 짐작**해서 보여 줍니다. 빨간불: 모델이 앞에서 멈출 것으로 예측 / 초록불: 빨간불에 서 있다가 모델이 출발을 예측 (3초 동안). 노란불은 없고, 서지 않고 지나가는 초록불에서는 안 켜집니다. **아직 제대로 작동하지 않을 수 있으니 꼭 신호를 직접 보세요** | 주행 → 신호등 → **신호등 사용** |
| 9 | **회전 안내** | 내비 앱이 길안내 중일 때 좌회전 · 우회전 · 왼쪽/오른쪽 차로 · U턴 · 고가 진입 · 지하차도 · 휴게소와 남은 거리 | 폰 내비 앱 길안내 중에만 |
| 10 | **방향지시등 화살표** | 깜빡이를 켜면 큰 속도 옆에 화살표 3개가 차례로 켜집니다 | 늘 동작 |
| 11 | **앞차 정보** | 앞차 위 주황 삼각형과 **거리 · 앞차 속도 · 도달**(지금 속도로 앞차 자리까지 몇 초). 도달 1초 미만 빨강, 2초 미만 주황 | 앞차가 있을 때만 |
| 12 | **레이더 물체** | 앞 레이더가 잡은 물체와 속도(km/h). 초록 = 같은 방향, 빨강 = 마주 오는 물체, 주황 **정지** = 서 있는 물체. 위 작은 숫자 = 옆으로 떨어진 거리(m, +왼쪽 / -오른쪽). 사람 · 차 · 오토바이는 구별하지 못합니다 | 화면 → **레이더 물체 표시** (여러 물체는 토글 → 레이더 트랙 사용 + 지원 차만) |
| 13 | **경로** | 흰 반투명 길 = 주행 모델이 예측한 진행 길. 가운데 **파란 줄** = openpilot이 조향 중 | 늘 보임 |
| 14 | **핸들** | 실제 핸들 각도대로 돌아갑니다. 초록 = openpilot 켜짐, 회색 = 운전자가 잠시 조작 중, 주황 · 빨강 = 경고, 짙은 파랑 = 꺼짐. **핸들 그림을 누르면 [경로 좌우 보정](#경로-좌우-보정-창) 창**이 열립니다 | 늘 보임 |
| 15 | **CPU** | 기기 CPU 온도와 사용률. 80°C 넘거나 90% 넘으면 빨갛게 깜빡입니다 | 화면 → **기기 상태** |
| 16 | **공기압** | 네 바퀴 타이어 공기압(psi). 위 줄 앞바퀴, 아래 줄 뒷바퀴. 31 미만은 빨강 | 화면 → **타이어 공기압** |
| 17 | **후측방 경고** | 옆 차로 뒤쪽에 차가 있으면 도로 양옆(앞차 정보 옆)에 노란 차량 표시. 그쪽으로 깜빡이를 켜면 **그 표시가 깜빡입니다**. 시속 30km 이상, 차에 후측방 감지(BSD)가 있어야 합니다 | 화면 → **후측방(BSD) 경고** |
| 18 | **운전자 모니터링 아이콘** | 실내 카메라가 얼굴을 보고 있는지. 잘 보면 선명, 아니면 흐릿 | 화면 → **운전자 모니터링 아이콘** (토글 → 운전자 모니터링이 '기본 사용'일 때만) |
| 19 | **REC 녹화 버튼** | 누르면 기기 화면을 동영상으로 녹화(버튼이 빨개짐), 다시 누르면 멈춤. 3분마다 나뉘어 저장 | 화면 → **녹화 버튼** (처음 값: 꺼짐) |

### 그림에 없는 표시

**연결 표시 (1번)** — 해당될 때만 왼쪽부터 붙어서 나옵니다.

| 표시 | 뜻 |
|---|---|
| **SCC2** (빨강) | SCC 버스2(롱컨) 차량 — 토글 → 롱컨을 켠 차 |
| **TMAP** | TmapNda가 NDA 방식(843)으로 내비 정보를 보내는 중 |
| **CARROT** | 당근 방식(7706)으로 내비 정보가 들어옴 — 당근내비, 당근 방식으로 설정한 TmapNda |
| (위 글자의 색) | 초록 = 정보(카메라 · 도로 제한 속도 · 회전 안내)가 들어오는 중, 회색 = 연결됐지만 아직 정보가 없음 |
| **HDA** (보라) | 차 순정 내비의 카메라 정보를 쓰는 중 (순정 내비가 있는 차만) |
| **RADAR** (주황) | 레이더 트랙 사용 중 — 토글 → 레이더 트랙 사용 |

**방지턱 (4번)** — 내비 앱이 과속방지턱을 알려 주면 단속 속도 대신 <img src="selfdrive/assets/images/speed_bump.png" height="32"> 그림이 나옵니다.

#### 설정 속도 칸 색

| 칸 색 | 뜻 |
|---|---|
| **파랑** | openpilot이 가감속을 하는 중 |
| **초록** | 단속 카메라 · 구간단속 안에서 제한 속도를 지키는 중 |
| **빨강 깜빡임** | 단속 제한 속도보다 2km/h 이상 빠름 — 속도를 줄이세요 |
| **반투명 흰색** | 조향만 하는 중 (가감속은 운전자) |
| **회색 '--'** | openpilot 꺼짐 |

#### 화면 테두리 색

| 테두리 | 뜻 |
|---|---|
| 초록 | openpilot 켜짐 |
| 회색 | 운전자가 잠시 조작 중 (가속페달 등) |
| 주황 · 빨강 | 경고 (빨강이면 곧 꺼지거나 바로 핸들을 잡아야 함) |
| 짙은 파랑 | 꺼짐 |

#### 경고 글

화면 아래 가운데에 나옵니다. openpilot이 꺼지는 경고에는 셋째 줄에 **'오픈파일럿이 꺼졌습니다'** 또는 **'오픈파일럿이 곧 꺼집니다'**가 붙습니다.
신호등을 켜 두었다면 빨간불에 서 있다 출발할 때 **'초록불로 바뀌었어요'** 알림과 소리가 납니다 (주행 → 신호등 → 초록불 알림).

#### 경로 좌우 보정 창

주행 중 **14번 핸들 그림을 누르면** 창이 열립니다. 차가 차로 안에서 한쪽으로 치우쳐 달릴 때 바로 고칩니다.
**-** 를 누르면 왼쪽으로, **+** 를 누르면 오른쪽으로 한 번에 5cm씩 옮깁니다. 핸들 그림을 다시 누르면 닫힙니다. (설정 → OPTECH → 조향 → 경로 좌우 보정과 같은 값)

#### 주행 중 화면 밝기

화면 → **주행 중 밝기**를 고르면 기어가 D(주행)일 때만 해당됩니다. 30초 동안 화면을 만지지 않으면 고른 밝기로 어두워지고, **화면 밝기 0%**를 고르면 화면이 완전히 검게 됩니다. 화면을 터치하거나 기어를 N·P·R에 두면 다시 밝아지고, 다시 D로 바꾼 뒤 30초가 지나면 다시 적용됩니다. 경고가 뜰 때도 바로 밝아집니다.

## 4. 기기 메뉴 설명

설정 화면 왼쪽에 **장치 · 네트워크 · 토글 · 소프트웨어 · OPTECH**가 있습니다. OPTECH 안에는 다시 **시작 · 주행 · 속도 · 조향 · 화면 · 고급** 탭이 있습니다.
값을 바꾸고 **재부팅**이 필요한 항목은 표에 적어 두었습니다.

### 4-1. 장치

| 항목 | 하는 일 |
|---|---|
| 동글 ID · 시리얼 | 기기 고유 번호 (문의할 때 알려 주세요) |
| 소프트 재시작 | 기기를 끄지 않고 openpilot만 다시 시작합니다 |
| 캘리브레이션 (위쪽 버튼) | 카메라 각도 보정값과 학습값을 지우고 openpilot을 다시 시작합니다. 기기를 다시 달았을 때 씁니다 |
| 운전자 카메라 [미리 보기] | 실내 카메라 화면을 봅니다. 얼굴이 잘 보이게 기기 각도를 맞출 때 씁니다 (시동 끈 상태) |
| 캘리브레이션 [초기화] | 카메라 각도 보정값만 지웁니다. 설명을 누르면 지금 기기가 몇 도 기울었는지 보여 줍니다 |
| 트레이닝 가이드 | openpilot 사용법 안내를 다시 봅니다 |
| 언어 변경 | 화면 언어를 바꿉니다 |
| 재부팅 / 다시 빌드 / 전원 종료 | 다시 빌드는 프로그램을 처음부터 다시 조립합니다 (10분 이상 걸림, 업데이트 뒤 이상할 때만) |

### 4-2. 네트워크

| 항목 | 하는 일 |
|---|---|
| 와이파이 설정 [열기] | 와이파이에 연결합니다 |
| 테더링 설정 [열기] | 기기를 핫스팟으로 만듭니다 (폰 내비 앱 연결, 주행 기록 받기에 씀) |
| IP 주소 | 지금 기기 주소 (SSH 접속, 주행 기록 받기에 씀) |
| SSH 사용 · SSH 키 | SSH 접속을 켜고, 접속할 GitHub 아이디의 키를 등록합니다 |

### 4-3. 토글

| 항목 | 하는 일 | 처음 값 |
|---|---|---|
| openpilot 사용 | 끄면 openpilot이 차를 제어하지 않습니다 (시동을 끈 뒤 적용) | 켜짐 |
| 롱컨 (Long Control) | SCC(레이더) 배선 개조를 한 차만 켜세요. openpilot이 가감속을 직접 합니다. **재부팅** | 꺼짐 |
| 레이더 트랙 사용 | SCC 정보 대신 레이더가 잡은 여러 물체 정보를 씁니다. 지원하는 차만 (예: 산타페 2022 하이브리드). 주행 화면의 레이더 물체 표시에도 필요 | 꺼짐 |
| LDWS 차량 (차로 유지 보조 없음) | 차선 이탈 경고(LDWS)만 있고 차로 유지 보조(LKAS)가 없는 차만 켜세요. 이런 차에서 조향이 안 되거나 계기판에 차로 유지 관련 오류가 뜰 때 씁니다 (OPKR의 'LDWS 차량 설정'과 같음). LKAS가 있는 차는 켜지 마세요. **재부팅** | 꺼짐 |
| 차선 이탈 경고 사용 | 시속 50km 이상에서 깜빡이 없이 차선을 밟으면 알려 줍니다 | |
| 미터법 사용 | km/h로 표시합니다 (끄면 mph) | |
| 운전자 카메라 녹화 및 업로드 | 실내 카메라 영상을 기록합니다 (보통 끔) | |
| **운전자 모니터링** | 누르면 설명을 보여 준 뒤 고릅니다. **재부팅** 필요<br>**기본 사용**: 카메라로 얼굴을 봅니다. 앞을 안 보거나 졸면 1분 뒤 경고, 1분 2초 경고음, 1분 8초 빨간 경고와 감속<br>**경도 사용**: 카메라를 쓰지 않습니다(발열 감소). 핸들 · 페달 · 버튼을 5분 동안 전혀 안 쓰면 경고와 감속<br>**사용 안 함**: 카메라도 경고도 없습니다 (추천하지 않음)<br>감속: 롱컨 차는 멈출 때까지, 순정 SCC 차는 설정 속도를 30km/h까지 낮춤. 비상등은 켜지지 않습니다 | 기본 사용 |

|---|---|

| 최신 업데이트 [확인] | 새 버전이 있는지 보고, 바뀐 내용을 보여 준 뒤 업데이트합니다 (받은 뒤 자동 재부팅) |
| 브랜치 이름 · 브랜치 커밋 · 운영체제 버전 | 설치된 브랜치와 버전 정보 |

### 4-5. OPTECH → 시작

| 항목 | 하는 일 |
|---|---|
| **차종 선택** (파란 버튼) | 내 차를 고릅니다. 브랜드 → 차종 → 연식 순서입니다. 국내 차 이름은 영어로 씁니다 (아반떼 = AVANTE, 그랜저 = GRANDEUR) |
| 차종별 설정 | 레이 EV · 포터 II EV를 고르면 차종 버튼 아래에 그 차 전용 설정이 열립니다 (아래 표) |

**차종별 설정** (그 차를 골랐을 때만 나옵니다)

| 차 | 항목 | 하는 일 | 처음 값 |
|---|---|---|---|
| 레이 EV · 포터 II EV | 크루즈 속도 자동 조절 | 페달 없이 쓸 때 openpilot이 크루즈 버튼을 대신 눌러 설정 속도를 바꿉니다 (커브 · 과속카메라 감속) | 꺼짐 |
| 레이 EV · 포터 II EV | 페달 사용 | comma 페달 장치를 단 경우에만 켜세요. openpilot이 가속페달로 가감속합니다. **재부팅** | 꺼짐 |
| 레이 EV · 포터 II EV | 페달 최대 밟는 양 | openpilot이 가속페달을 최대 몇 %까지 밟을지 | 레이 70, 포터 40 |
| 레이 EV | 페달 세게 (당근) | 같은 명령에 페달을 약 2배 더 밟습니다. 가속이 정말 약할 때만. **재부팅** | 꺼짐 |
| 레이 EV | 속도 오차 보정 (Ki) | 설정 속도와 실제 속도가 계속 어긋날 때 조금씩 맞춥니다. **재부팅** | 50 |

### 4-6. OPTECH → 주행

| 구역 | 항목 | 하는 일 | 처음 값 |
|---|---|---|---|
| (맨 위) | 버튼 사용법 안내 | 크루즈 버튼, SET / RES, CANCEL, 브레이크가 무엇을 켜고 끄는지 보여 줍니다 (2. 운전하는 방법과 같음). 예전 '사용 방식' 선택은 없어졌습니다 | - |
| 브레이크 | **브레이크 후 다시 켜기** | 브레이크를 밟았다 뗐을 때: **원래 설정 속도로** / **현재 속도로** (줄인 그 속도로) / **다시 켜지 않음** (RES(+)나 SET(-)을 눌러야 켜짐). '스마트 크루즈 컨트롤 작동조건이 아님'이 자주 뜨면 '다시 켜지 않음' | 현재 속도로 |
| 브레이크 | 악셀로 다시 켜기 | 브레이크로 꺼진 가감속이 악셀을 밟고 있을 때도 다시 켜집니다 (시속 30km 이상, 0.5초 넘게 밟을 때, 그 속도로). 핸들을 많이 꺾었거나 빨간불로 판단될 때는 안 켜짐 | 꺼짐 |
| 브레이크 | 소프트홀드 | 정차 후 브레이크를 떼도 차를 잡아 둡니다. 사용 안 함 / 사용 / SCC와 함께 사용 | 사용 안 함 |
| 크루즈 버튼 | 크루즈 알림음 | 켜지고 꺼질 때 소리 크기. 끄기 / 작게 / 크게 | 작게 |
| 크루즈 버튼 | 버튼 한 번에 바뀌는 속도 | + / - 버튼 한 번에 바뀌는 km/h | 10 |
| 과속카메라 | **카메라 감속** | 과속카메라 앞에서 제한 속도까지 미리 줄입니다. 켜면 아래 항목이 나타납니다. 가감속이 켜져 있을 때만 줄이고, GPS가 잡혀야 합니다 | 꺼짐 |
| 과속카메라 | 감속 시작 (초 전) | 카메라 몇 초 전부터 줄이기 시작할지 (시속 100km에서 22초 ≈ 600m) | 22 |
| 과속카메라 | 감속 끝 (초 전) | 카메라 몇 초 전까지 목표 속도에 맞출지 | 6 |
| 과속카메라 | 목표 속도 (제한 속도의 %) | 100 = 제한 속도 그대로, 105 = 5% 빠르게. 단속 기준을 넘지 않게 주의 | 100 |
| 과속카메라 | 과속 단속 알림 | 카메라 앞에서 속도를 줄이기 시작할 때 차의 차선 이탈 경고를 빌려 알립니다. 사용 안 함(속도만 줄임) / 차선 경고 1 · 2 · 3 (계기판 경고 + 경고음, 핸들 진동이 있는 차는 핸들도 떨림). 보통 제네시스 G80 · G90은 1, 다른 현대 · 기아는 2 | 사용 안 함 |
| 과속카메라 | 내비 연동 방식 | 쓰는 폰 내비 앱. 사용 안 함(내장 DB만) / TmapNda / 당근내비. 앱을 고르면 앱 정보가 없을 때 내장 DB와 차 순정 내비 정보로 채웁니다 (아래 [5. 폰 내비 앱 연동](#5-폰-내비-앱-연동-선택)). **재부팅** | TmapNda |
| 과속카메라 | 내장 카메라 DB | 내비 앱 없이 기기 GPS와 전국 고정식 카메라 약 3만 1천 대 위치로 찾습니다. 구간단속은 끝날 때까지 지킵니다. 이동식 · 새 카메라는 모르고, 반대 차로 카메라에도 줄일 수 있습니다. **재부팅** | 꺼짐 |
| 신호등 | **신호등 사용** ⚠️ | 주행 모델의 예측으로 빨간불 · 초록불을 짐작해 주행 화면에 신호등을 보여 줍니다. **차를 멈추거나 출발시키지는 않습니다.** 아직 제대로 작동하지 않을 수 있습니다. 끄면 신호등 표시와 초록불 알림이 모두 꺼집니다 | 켜짐 |
| 신호등 | 초록불 알림 ⚠️ | 빨간불에 서 있다 초록불로 바뀌면 소리와 '초록불로 바뀌었어요'. 앞차가 출발할 때도 울릴 수 있고 늦거나 빠를 수 있으니 **출발 전 꼭 신호를 직접 확인**하세요. '신호등 사용'이 켜져 있을 때만 보입니다 | 켜짐 |

| 출발·정지 | 앞차 뒤 정지 거리 | 앞차 뒤에 멈출 때의 거리 (cm) | 600 |

## 5. 폰 내비 앱 연동 (선택)

내비 앱 없이 과속카메라 감속만 쓰려면 주행 → **카메라 감속 + 내장 카메라 DB**만 켜면 됩니다. 도로 제한 속도, 과속방지턱, 회전 안내까지 받으려면 아래처럼 폰 내비 앱을 연결하세요.

1. 폰에 내비 앱을 설치합니다. 두 앱 모두 OPTECH가 만든 앱이 아니므로, 만든 곳에서 직접 받으세요.
   - **TmapNda**: [github.com/Rusiperso/TmapNda](https://github.com/Rusiperso/TmapNda)의 Releases. 안드로이드 8.0 이상. 앱의 오픈파일럿 연결을 **NDA 방식**으로 두면 주행 화면에 TMAP으로 떠서 당근내비(CARROT)와 구별됩니다. 처음 설정대로면 앱 사용 기록(위치 · 목적지 포함)을 앱 개발자에게 보내니, 원하지 않으면 앱 설정에서 끄세요.
   - **당근내비**: 당근 쪽 배포처. 안드로이드 11 이상.
2. 폰과 C2를 **같은 와이파이** 또는 **C2 핫스팟**에 연결합니다 (고급 → 부팅 시 핫스팟 켜기).
3. 주행 → **카메라 감속** 켜기, **내비 연동 방식**에서 쓰는 앱(TmapNda 또는 당근내비)을 고르고 재부팅합니다.
4. 주행 화면 왼쪽 위에 초록 **TMAP** 또는 **CARROT**이 나오면 정보가 들어오는 것입니다. 회색이면 연결만 되고 아직 정보가 없는 것입니다.

## 6. 주행 기록 보내기

문제가 생겼을 때 기록을 보내 주시면 원인을 찾을 수 있습니다.

1. 폰을 C2와 **같은 와이파이**에 연결하거나, 폰 핫스팟에 C2를 연결합니다.
2. 설정 → OPTECH → 고급 → **주행 기록 내려받기 → QR 보기**
3. 폰 카메라로 QR 코드를 찍고, 열린 화면에서 **'전체 기록 한 번에 받기'**를 누릅니다.
4. 받은 파일을 카카오톡으로 보내 주세요. (위치 좌표는 들어 있지 않습니다. 15분 뒤 자동으로 닫힙니다)

기록에는 켜짐 · 꺼짐, 경고, 순정 SCC 상태, 계기판 SCC 안내, 전방 충돌방지 고장 신호, 차선 인식, 브레이크등, openpilot이 보낸 크루즈 버튼이 1초마다 들어 있습니다.

## 7. 상황별 해결

**한 번에 하나만, 조금씩 바꾸고** 운전해 보세요. 나아지지 않으면 처음 값으로 되돌리세요.

| 이럴 때 | 어디서 | 이렇게 |
|---|---|---|
| 차로 안에서 한쪽으로 쏠려요 | 주행 화면 핸들 그림 누르기, 또는 조향 → 경로 좌우 보정 | 오른쪽으로 쏠리면 **-**, 왼쪽으로 쏠리면 **+** 쪽으로 조금씩 |
| 커브에서 늦게 꺾이거나 바깥으로 밀려요 | 조향 → NNFF / NNFF 라이트 | 먼저 켜 보기 (재부팅) |
| 그래도 커브에서 늦게 꺾여요 | 조향 → 조향 반응 지연 보정 | 30 → **35** |
| 커브에서 너무 많이 꺾여요 | 조향 → 실시간 조향비 적용 | 100 → **95** |
| 커브에서 너무 많이 감속해요 | 조향 → 커브 감속 비율 | 100 → **120** |
| 커브에서 감속이 부족해요 | 조향 → 커브 감속 비율 | 100 → **85** |
| 출발이 굼떠요 | 속도 → 출발 가속 | 0 → **30** |
| 출발이 너무 급해요 | 속도 → 재출발 가속 | 10 → **7** |
| 정차 중 차가 앞으로 밀려요 | 속도 → 정지 유지 힘 | 30 → **50** |
| 앞차 뒤에 너무 가까이 / 멀리 서요 | 속도 → 앞차 뒤 정지 거리 | 50cm씩 늘리거나 줄이기 |
| 설정 속도가 저절로 올라가요 | 속도 → 제한속도까지 자동 올림 / 가속페달 속도 맞춤 상한 | **0** |
| 과속카메라에서 감속을 안 해요 | 주행 → 카메라 감속, 내장 카메라 DB | 둘 다 켜고 재부팅. 주행 화면에서 GPS가 '잡힘'인지 확인 |
| 정차 후 브레이크를 떼면 차가 굴러가요 | 주행 → 소프트홀드 | **사용** |
| '스마트 크루즈 컨트롤 작동조건이 아님'이 자주 떠요 | 주행 → 브레이크 후 다시 켜기 | **다시 켜지 않음** |
| 밤이나 선글라스 때문에 전방 주시 경고가 잦아요 | 토글 → 운전자 모니터링 | **경도 사용** → 재부팅 |
| 설정을 보는데 금방 주행 화면으로 돌아가요 | 화면 → 화면 유지 시간 | **5분** 또는 **10분** |
| 밤에 화면이 눈부셔요 | 화면 → 주행 중 밝기 | **30%** 정도 |
| 신호등 표시가 자꾸 틀려요 | 주행 → 신호등 → 신호등 사용 | **끄기** |
| 계기판에 이상한 경고가 떠요 | 고급 → 주행 기록 내려받기 | 기록을 받아 보내 주세요 |

## 8. 지원 차량

### 현대 · 기아 · 제네시스
* 일반 CAN 차량 대부분. 전체 목록은 기기의 **차종 선택**에서 볼 수 있습니다.
* 가감속(롱컨)까지 쓰려면 **SCC 모듈(레이더) 배선 개조**가 필요합니다 (SCC의 CCAN 연결을 끊고 판다의 CAN2에 연결). 개조한 뒤 토글 → **롱컨**을 켜세요.

### 스마트 크루즈(SCC)가 없는 차 — 레이 EV, 포터 II EV
* 기본은 **조향만** 합니다. 속도는 차의 크루즈 컨트롤이 유지합니다.
* **comma 페달 장치**를 달면 openpilot이 가속페달로 가감속을 맡습니다.
* 차종을 고르면 시작 탭에 **레이 EV 설정 / 포터 II EV 설정**이 따로 나옵니다.

### 스마트 크루즈(SCC)가 없는 하위 트림
* 아반떼 CN7 · 아반떼 하이브리드 CN7, 코나 OS · 코나 일렉트릭 OS, 베뉴, 셀토스(2023~24), K3(2019 · 2021), G70(2021)
* 아반떼 · 코나 · 셀토스 · K3는 **보통 차종을 그대로 고르면 됩니다.** 시동을 걸 때 스마트 크루즈 신호가 없으면 자동으로 SCC 없는 트림으로 동작합니다.
* 베뉴와 G70은 목록에서 이름 끝이 **NO SCC**인 것을 고르세요.
* **조향만** 합니다. 앞차와의 거리는 항상 운전자가 지켜 주세요. 아직 실제 차로 시험하지 않았습니다.

### 현대 · 기아 외 차종
* 이 브랜치는 **현대 · 기아 · 제네시스 전용**입니다. 쉐보레 · 토요타 · 혼다 등 다른 브랜드는 **optech-spst**(준비 중)를 쓰세요.

> 레이 EV · 포터 II EV와 스마트 크루즈가 없는 하위 트림은 아직 실제 차로 충분히 시험하지 않았습니다. 처음에는 안전한 곳에서 조심해서 확인해 주세요.
